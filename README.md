# Ha Luan Portfolio

A responsive student portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `app.js` — navigation, project filters, modal details and contact-form UI
- `profile.jpg` — add your own real profile photo before submitting

## Run locally
Open `index.html` in a browser.

## Before submission
1. Replace the profile photo with your own photo.
2. Replace the placeholder email and GitHub username.
3. Review the About and Projects sections and make sure they describe your actual work.
4. Add real project links/screenshots if available.
5. Push the folder to a public GitHub repository.
6. Enable GitHub Pages from Settings → Pages → `main` branch.
